# Private progress

`progress.example.json` is an empty illustrative template. `scripts/roadmap.py init` creates `progress.json`, `scripts/system_profile.py --write-local` creates `system-profile.local.json`, and `scripts/spaced_review.py add 00` creates `reviews.local.json`. All three **must remain local** and are ignored by Git; they can contain sensitive context. Do not commit them to public forks/templates. Public portfolios should be separate redacted case studies.

The [spaced-review guide](../docs/SPACED-REVIEW.md) describes a stage-level, private review reminder. Its history never certifies independent competence.
