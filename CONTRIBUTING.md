# Contributing

This repository is a learning template, not a central store for everyone's progress.

1. Read [the learning contract](docs/ASSESSMENT.md) and [security policy](SECURITY.md).
2. Fork for improvements to curriculum, tests, translations or public samples. For personal learning, prefer **Use this template** after the maintainer enables the setting.
3. Open an issue describing the gap and an acceptance criterion.
4. Use a focused branch and PR. Provide before/after docs, tests, and a short explanation of changes.
5. Do not include credentials, unrelated data dumps, scraped copyrighted materials or generated fake results presented as verified.
6. Ensure `python3 scripts/validate_repo.py` and `python3 -m unittest discover -s projects/datapulse/tests -v` pass.

Learners keep personal learning status in their own repository; the original public template contains no accounts or credentials.
