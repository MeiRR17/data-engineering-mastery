# Stage 00 — Onboarding, Environment and Data Flow

**Track:** Foundations  
**Prerequisite:** None  
**Outcome:** A privacy-preserving readiness report, safe workspace paths, a valid pipeline DAG and sanitized learning evidence.

[Guided notebook](../../notebooks/00_data_journey.ipynb) · [Hands-on lab](../../labs/00-onboarding/README.md) · [Assessment rubric](../../docs/ASSESSMENT.md) · [Full roadmap](../../README.md)

## Why this matters

- Git branches, commits, pull requests and test evidence.
- Python 3.11+, terminal basics and repository navigation.
- Extract → Validate → Curate → Serve and ETL vs ELT.
- No automatic device inventory or credential collection.

The goal is not to memorize tool commands. You must predict the output, write your own code, intentionally reproduce a failure, repair it, and explain the operational tradeoffs.

## Learning workflow

1. Open the guided notebook **visually** in VS Code, predict each assertion, then run its code cells. Use [the VS Code setup guide](../../docs/VS-CODE-LEARNING-SETUP.md) if the notebook opens as JSON.
2. Read the official documentation linked in the notebook or lab and sketch the data flow.
3. Run the instructor grader only to confirm the teaching exercise itself works:

~~~bash
python3 labs/00-onboarding/grade.py --reference
~~~

4. Run the learner grader and implement the unfinished starter. It is **expected to fail at first**:

~~~bash
python3 labs/00-onboarding/grade.py
~~~

5. Add tests, investigate one injected failure, record sanitized results and open a learner PR. Use AI for hints or code review after attempting the solution, not as a substitute for an independent exam.

## Required tasks

- [ ] Report Python/Git/workspace readiness from explicit inputs.
- [ ] Topologically order source/validate/curate/serve steps; reject cycles.
- [ ] Prove path traversal cannot escape the learner's workspace.
- [ ] Submit a brief reflection and one independently designed failure case.

## Independent conceptual check (without AI)

1. What differs between a Data Engineer, Analyst and ML Engineer?
2. Why does reproducibility matter when data may be replayed?

## Exit gate

Pass the 12 onboarding tests on student-owned code, explain the data flow and open a clean PR without secrets.

You must also document assumptions, reproducible commands, risks and an original transfer scenario in your PR. No credentials, private data or unauthorized writes are permitted. Passing instructor CI does not certify a learner or prove production deployment.
