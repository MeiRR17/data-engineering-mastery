# שלב 00: הקמה ואבחון — Foundation & Setup

**רמת יעד:** יסודות  
**שלבי קדם:** ללא  
**תוצר מרכזי:** חבילת אבחון, סביבת פיתוח ועץ החלטות אישי

## למה לומדים את זה?
Git, Python 3.11+, PostgreSQL, Shell, containers, GitHub connection; להבין את תפקיד ה-Data Engineer.

## סדר עבודה
1. קרא את חומר הרקע והתיעוד הרשמי הרלוונטי (לא מדריך וידאו בלבד).
2. פתח Issue עם הסעיף הזה בריפו האישי שלך, וצור branch בשם `learn/00-<short-topic>`.
3. יישם את המשימות בעצמך. בקש מ-AI רמזים וביקורת, לא פתרון מלא לפני ניסיון אישי.
4. הוסף בדיקות, תיעוד, והסבר של החלטות ופשרות.
5. פתח PR וסמן אותו Ready for review רק כאשר כל בדיקות CI עברו.
6. השלם מבחן מעבר ורשום ראיות להתקדמות עם `python3 scripts/roadmap.py complete 00 --evidence <PR-or-path> --reflection <summary>`.

## משימות חובה
- [ ] בדיקת גרסאות Python/Git
- [ ] שכפול הריפו והפעלת unittest
- [ ] אבחון SQL, Python, Linux והסבר ETL לעומת ELT

## מבחן הבנה (ללא AI)
1. מהו ההבדל בין Data Engineer, Data Analyst ו-ML Engineer?
2. מדוע צריך reproducibility בתהליכי נתונים?

- [ ] בדיקות אוטומטיות רלוונטיות עוברות (או הסבר כתוב מדוע לא ניתן להריצן).
