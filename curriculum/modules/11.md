# שלב 11: מידע בזמן אמת — Streaming & Kafka

**רמת יעד:** העמקה מתקדמת  
**שלבי קדם:** 10  
**תוצר מרכזי:** Streaming simulation ותיעוד semantic guarantees

## למה לומדים את זה?
Kafka, producers, consumers, offsets, ordering, watermarks, late events, exactly-once semantics.

## סדר עבודה
1. קרא את חומר הרקע והתיעוד הרשמי הרלוונטי (לא מדריך וידאו בלבד).
2. פתח Issue עם הסעיף הזה בריפו האישי שלך, וצור branch בשם `learn/11-<short-topic>`.
3. יישם את המשימות בעצמך. בקש מ-AI רמזים וביקורת, לא פתרון מלא לפני ניסיון אישי.
4. הוסף בדיקות, תיעוד, והסבר של החלטות ופשרות.
5. פתח PR וסמן אותו Ready for review רק כאשר כל בדיקות CI עברו.
6. השלם מבחן מעבר ורשום ראיות להתקדמות עם `python3 scripts/roadmap.py complete 11 --evidence <PR-or-path> --reflection <summary>`.
