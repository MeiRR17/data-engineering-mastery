# Stage 12 — Production Reliability, Monitoring, Security & Governance

**Prerequisite:** Stage 11 streaming/restart/offset safety.  
**Target artifact:** a complete *offline* incident drill with measured quality/availability/freshness, secure local backup/restore, role checks and cost-risk analysis.

[**Open the Stage 12 lab**](../../labs/12-reliability/README.md) · [Assessment rubric](../../docs/ASSESSMENT.md)

## What the learner does

~~~bash
python3 labs/12-reliability/grade.py --reference
python3 labs/12-reliability/incident_drill.py
python3 labs/12-reliability/grade.py
~~~

The third command intentionally fails until you fill in six functions. The instructor reference must pass **27 distinct scenarios**. All assets are synthetic and local.

### Required evidence

1. [ ] Define availability, freshness, data quality and bounded error budget using UTC.
2. [ ] Design alerts for breached thresholds and identify which alerts wake an operator.
3. [ ] Build a **least-privilege action table** and test viewer/operator/admin denial paths.
4. [ ] Create a SQLite backup and restore it to an **isolated new path**, with checksum, schema and row-count verification.
5. [ ] Inject synthetic corruption and demonstrate a failed integrity gate.
6. [ ] Publish an incident runbook with triage, containment, recovery, verification, RPO/RTO assumptions, postmortem and owner.
7. [ ] Forecast costs with explicit data volume and units, then discuss omitted vendor costs.
8. [ ] Answer a new incident scenario independently and open a PR with sanitized evidence.

**Not demonstrated:** production RLS/IAM, real remote alerting, protected backup encryption, live Supabase restore, quantified uptime, real cloud bills or an accredited credential.
