# Stage 13 — Capstone, Portfolio, Independent Exam & Career

**Prerequisites:** Stages 00–12 and their learning gates.  
**Objective:** prove initial Data Engineering competency with a complete, reproducible event-to-analytics project, plus an interview and an independent unseen transfer.

[**Capstone instructions**](../../capstone/README.md) · [Formal project specification](../../capstone/specification.md) · [Final assessment protocol](../../docs/FINAL-ASSESSMENT.he.md)

## Training steps

1. Read the full specification. Identify the business problem, success metrics, constraints, data grains and trust boundaries.
2. Run the integrated reference:

~~~bash
python3 capstone/grade.py --reference
python3 capstone/demo.py
~~~

3. Implement `capstone/starter.py` independently and run `python3 capstone/grade.py` until all **22 integration tests** pass. Use your previous Stage 01–12 exercises but don't copy instructor solutions.
4. Demonstrate four accepted event IDs, two safe dead-letter records, a blocked quality run and idempotent accepted recovery.
5. Show the read-only Serving metrics and the effect of NULL magnitude on average. Demonstrate warning on blocked/freshness scenario.
6. Create a verified backup into an isolated new file. Prove no unexpected data loss or partial writes.
7. Build a deterministic release artifact; simulate promotion and rollback without altering live state.
8. Write at least **three ADRs**, incident report, SLO/Cost scenario, tests, threat model and a clear portfolio README.
9. Defend a 10-minute demo, SQL/system design interview and unseen novel source or failure scenario.
10. Submit the complete evidence bundle for qualified independent review.

## Evaluation requirements

- [ ] Automated capstone grader green on student-authored code, with source hash and logs.
- [ ] Interview: SQL, modeling, event time, orchestration, quality, security, failure recovery and scale tradeoffs.
- [ ] Two independent no-AI transfer tasks and a fault-recovery exercise.
- [ ] No unresolved P0 security, data-loss or data-integrity failures.
- [ ] External or qualified reviewer records rubric scoring and checks practical evidence.
- [ ] Student describes precisely which parts were run locally, in Kafka, in Spark and in cloud.

**A green CI run for instructor reference does not complete this stage or award a certificate.** The template is a training resource; only a real learner's independent work and reviewer decision can substantiate a competency claim.
