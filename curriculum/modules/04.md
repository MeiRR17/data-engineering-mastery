# שלב 04: Supabase בענן — Supabase & Postgres Cloud

**רמת יעד:** יכולת מקצועית  
**שלבי קדם:** 03  
**תוצר מרכזי:** Supabase project נפרד עם סכמת raw+curated

## למה לומדים את זה?
Supabase local stack, migration, keys, RLS, private schemas, dev/staging/prod separation.

## סדר עבודה
1. קרא את חומר הרקע והתיעוד הרשמי הרלוונטי (לא מדריך וידאו בלבד).
2. פתח Issue עם הסעיף הזה בריפו האישי שלך, וצור branch בשם `learn/04-<short-topic>`.
3. יישם את המשימות בעצמך. בקש מ-AI רמזים וביקורת, לא פתרון מלא לפני ניסיון אישי.
4. הוסף בדיקות, תיעוד, והסבר של החלטות ופשרות.
5. פתח PR וסמן אותו Ready for review רק כאשר כל בדיקות CI עברו.
6. השלם מבחן מעבר ורשום ראיות להתקדמות עם `python3 scripts/roadmap.py complete 04 --evidence <PR-or-path> --reflection <summary>`.
