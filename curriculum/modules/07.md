# שלב 07: איכות, חוזים ומקור — Data Quality, Contracts & Lineage

**רמת יעד:** יכולת מקצועית  
**שלבי קדם:** 06  
**תוצר מרכזי:** quality gates + data contract ו-lineage map

## למה לומדים את זה?
schema validation, checks, Great Expectations/dbt tests, anomaly thresholds, lineage, reproducibility.

## סדר עבודה
1. קרא את חומר הרקע והתיעוד הרשמי הרלוונטי (לא מדריך וידאו בלבד).
2. פתח Issue עם הסעיף הזה בריפו האישי שלך, וצור branch בשם `learn/07-<short-topic>`.
3. יישם את המשימות בעצמך. בקש מ-AI רמזים וביקורת, לא פתרון מלא לפני ניסיון אישי.
4. הוסף בדיקות, תיעוד, והסבר של החלטות ופשרות.
5. פתח PR וסמן אותו Ready for review רק כאשר כל בדיקות CI עברו.
6. השלם מבחן מעבר ורשום ראיות להתקדמות עם `python3 scripts/roadmap.py complete 07 --evidence <PR-or-path> --reflection <summary>`.
