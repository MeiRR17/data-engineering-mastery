# Stage 07 — איכות נתונים, חוזים ומקור הנתונים

**קדם:** Stage 06 (תזמור ו־Replay). **תוצר:** שער איכות אמין עם בדיקות Schema, Freshness, Completeness, Quarantine, Lineage ו־Rollback.

[פתיחת המעבדה המעשית](../../labs/07-quality/README.md) · [רובריקה](../../docs/ASSESSMENT.md)

## סדר לימוד

1. למד להבחין בין נתון תקין מבחינת טיפוס, נתון עדכני ונתון נכון מבחינה עסקית.
2. בדוק את חוזה הנתונים ב־[contract.json](../../labs/07-quality/contract.json). יש בו גרסה, שדות מחייבים וספים.
3. הרץ תחילה את בדיקות הייחוס, ואז את קובץ הלומד שאינו פתור בהתחלה.

~~~bash
python3 labs/07-quality/grade.py --reference
python3 labs/07-quality/grade.py
~~~

4. יישם אימות רשומות, מדדי איכות, הסגר בטוח, פרסום אטומי ושמירת שושלת נתונים (Lineage).
5. שבור במכוון Schema, הזן כפילות, השתמש ב־Timestamp ללא אזור זמן והדגם קריסה לפני Commit.
6. הסבר מדוע Batch שנחסם עדיין מחייב תיעוד תפעולי, ומדוע אסור להכניס תוכן פרטי מלא להסגר.
7. הוסף מקרה קצה משלך וענה על מבחן העברה ללא AI.

## מדעי המחשב בדרך

Type Systems ו־API Evolution עבור Schema Drift; Graph Theory עבור Lineage; Transactions ו־Failure Isolation עבור פרסום אטומי; Event Time עבור Freshness; Data Minimization לשמירת פרטי שגיאה בטוחה.
