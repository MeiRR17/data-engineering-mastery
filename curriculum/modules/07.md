# Stage 07 — Data Contracts, Quality Gates and Lineage

**Track:** Core  
**Prerequisite:** 06  
**Outcome:** Versioned schema checks, completeness/freshness metrics, quarantine and atomic publishing.

[Guided notebook](../../notebooks/07_quality_contracts.ipynb) · [Hands-on lab](../../labs/07-quality/README.md) · [Assessment rubric](../../docs/ASSESSMENT.md) · [Full roadmap](../../README.md)

## Why this matters

- Schema contracts and backward compatibility.
- Structural validation vs freshness vs business correctness.
- Safe quarantine, lineage and provenance.
- Atomic all-or-nothing publishing of quality-checked batches.

The goal is not to memorize tool commands. You must predict the output, write your own code, intentionally reproduce a failure, repair it, and explain the operational tradeoffs.

## Learning workflow

1. Open the guided notebook **visually** in VS Code, predict each assertion, then run its code cells. Use [the VS Code setup guide](../../docs/VS-CODE-LEARNING-SETUP.md) if the notebook opens as JSON.
2. Read the official documentation linked in the notebook or lab and sketch the data flow.
3. Run the instructor grader only to confirm the teaching exercise itself works:

~~~bash
python3 labs/07-quality/grade.py --reference
~~~

4. Run the learner grader and implement the unfinished starter. It is **expected to fail at first**:

~~~bash
python3 labs/07-quality/grade.py
~~~

5. Add tests, investigate one injected failure, record sanitized results and open a learner PR. Use AI for hints or code review after attempting the solution, not as a substitute for an independent exam.

## Required tasks

- [ ] Inspect the versioned contract.json and predict a failed threshold.
- [ ] Implement all six learner functions and pass the 27 quality scenarios.
- [ ] Inject a schema-drift column, naive timestamp, duplicate and pre-commit crash.
- [ ] Explain why blocking publication still requires an audit event.

## Independent conceptual check (without AI)

1. Can a record be structurally valid but commercially incorrect?
2. What raw information should a dead-letter record never expose?

## Exit gate

Pass 27 reference/learner scenarios, including rollback, replay and safe lineage, and write an unseen test.

You must also document assumptions, reproducible commands, risks and an original transfer scenario in your PR. No credentials, private data or unauthorized writes are permitted. Passing instructor CI does not certify a learner or prove production deployment.
