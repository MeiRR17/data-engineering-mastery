# שלב 09: פריסה ו-DevOps — Cloud Delivery & CI/CD

**רמת יעד:** העמקה מתקדמת  
**שלבי קדם:** 08  
**תוצר מרכזי:** Pipeline שנבדק ב-PR ונפרס ידנית עם Rollback

## למה לומדים את זה?
CI, migrations, environment boundaries, IAM, service accounts, Docker, infra as code, zero-downtime deploy.

## סדר עבודה
1. קרא את חומר הרקע והתיעוד הרשמי הרלוונטי (לא מדריך וידאו בלבד).
2. פתח Issue עם הסעיף הזה בריפו האישי שלך, וצור branch בשם `learn/09-<short-topic>`.
3. יישם את המשימות בעצמך. בקש מ-AI רמזים וביקורת, לא פתרון מלא לפני ניסיון אישי.
4. הוסף בדיקות, תיעוד, והסבר של החלטות ופשרות.
5. פתח PR וסמן אותו Ready for review רק כאשר כל בדיקות CI עברו.
6. השלם מבחן מעבר ורשום ראיות להתקדמות עם `python3 scripts/roadmap.py complete 09 --evidence <PR-or-path> --reflection <summary>`.

- [ ] קיימת ראיה: PR, commit, log מסונן או תיעוד בצירוף פרויקט הניתן להרצה.
