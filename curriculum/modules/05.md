# שלב 05: מידול אנליטי — Modeling & Warehouse

**רמת יעד:** יכולת מקצועית  
**שלבי קדם:** 04  
**תוצר מרכזי:** analytics mart עם עובדות, ממדים ו-daily rollups

## למה לומדים את זה?
Kimball/star schema, fact/dimension, grain, SCD Type 2, partitioning, Parquet, DuckDB, marts.

## סדר עבודה
1. קרא את חומר הרקע והתיעוד הרשמי הרלוונטי (לא מדריך וידאו בלבד).
2. פתח Issue עם הסעיף הזה בריפו האישי שלך, וצור branch בשם `learn/05-<short-topic>`.
3. יישם את המשימות בעצמך. בקש מ-AI רמזים וביקורת, לא פתרון מלא לפני ניסיון אישי.
4. הוסף בדיקות, תיעוד, והסבר של החלטות ופשרות.
5. פתח PR וסמן אותו Ready for review רק כאשר כל בדיקות CI עברו.
6. השלם מבחן מעבר ורשום ראיות להתקדמות עם `python3 scripts/roadmap.py complete 05 --evidence <PR-or-path> --reflection <summary>`.
