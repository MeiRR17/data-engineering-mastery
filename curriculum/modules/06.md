# שלב 06: תזמור ובקרה — Orchestration & Scheduling

**רמת יעד:** יכולת מקצועית  
**שלבי קדם:** 05  
**תוצר מרכזי:** DAG אוטומטי להפעלת pipeline

## למה לומדים את זה?
Airflow או Kestra, DAGs, dependencies, schedules, backfills, SLAs, retry/timeouts, secrets.

## סדר עבודה
1. קרא את חומר הרקע והתיעוד הרשמי הרלוונטי (לא מדריך וידאו בלבד).
2. פתח Issue עם הסעיף הזה בריפו האישי שלך, וצור branch בשם `learn/06-<short-topic>`.
3. יישם את המשימות בעצמך. בקש מ-AI רמזים וביקורת, לא פתרון מלא לפני ניסיון אישי.
4. הוסף בדיקות, תיעוד, והסבר של החלטות ופשרות.
5. פתח PR וסמן אותו Ready for review רק כאשר כל בדיקות CI עברו.
6. השלם מבחן מעבר ורשום ראיות להתקדמות עם `python3 scripts/roadmap.py complete 06 --evidence <PR-or-path> --reflection <summary>`.
