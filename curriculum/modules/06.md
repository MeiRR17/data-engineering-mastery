# Stage 06 — Pipeline Orchestration, Retries and Backfill

**Track:** Core  
**Prerequisite:** 05  
**Outcome:** A small durable orchestrator with checkpoint-safe recovery and 17 reference failure scenarios.

[Guided notebook](../../notebooks/06_dag_recovery.ipynb) · [Hands-on lab](../../labs/06-orchestration/README.md) · [Assessment rubric](../../docs/ASSESSMENT.md) · [Full roadmap](../../README.md)

## Why this matters

- DAG ordering and cycle detection.
- Bounded retries and retry-safe side effects.
- Partitioned backfill windows and checkpoints.
- Exactly-once local effects vs delivery acknowledgement.

The goal is not to memorize tool commands. You must predict the output, write your own code, intentionally reproduce a failure, repair it, and explain the operational tradeoffs.

## Learning workflow

1. Open the guided notebook **visually** in VS Code, predict each assertion, then run its code cells. Use [the VS Code setup guide](../../docs/VS-CODE-LEARNING-SETUP.md) if the notebook opens as JSON.
2. Read the official documentation linked in the notebook or lab and sketch the data flow.
3. Run the instructor grader only to confirm the teaching exercise itself works:

~~~bash
python3 labs/06-orchestration/grade.py --reference
~~~

4. Run the learner grader and implement the unfinished starter. It is **expected to fail at first**:

~~~bash
python3 labs/06-orchestration/grade.py
~~~

5. Add tests, investigate one injected failure, record sanitized results and open a learner PR. Use AI for hints or code review after attempting the solution, not as a substitute for an independent exam.

## Required tasks

- [ ] Implement dependencies and reject missing or circular edges.
- [ ] Compute a strictly bounded date range for backfill.
- [ ] Inject temporary source failure, duplicate delivery and a crash after commit.
- [ ] Write a short incident report with hypothesis, root cause, fix and regression.

## Independent conceptual check (without AI)

1. Why should a backfill never be completely unbounded?
2. How do you recover after a commit whose acknowledgement was lost?

## Exit gate

Pass all local orchestration tests and submit an independently reasoned new failure scenario.

You must also document assumptions, reproducible commands, risks and an original transfer scenario in your PR. No credentials, private data or unauthorized writes are permitted. Passing instructor CI does not certify a learner or prove production deployment.
