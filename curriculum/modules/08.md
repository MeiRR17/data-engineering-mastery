# שלב 08: הצגת מידע ואנליטיקה — Analytics Serving & Dashboards

**רמת יעד:** יכולת מקצועית  
**שלבי קדם:** 07  
**תוצר מרכזי:** Dashboard מקור נתונים בטוח + data API

## למה לומדים את זה?
REST/PostgREST, view security_invoker, materialized views, BI, KPIs, metrics definitions, pagination.

## סדר עבודה
1. קרא את חומר הרקע והתיעוד הרשמי הרלוונטי (לא מדריך וידאו בלבד).
2. פתח Issue עם הסעיף הזה בריפו האישי שלך, וצור branch בשם `learn/08-<short-topic>`.
3. יישם את המשימות בעצמך. בקש מ-AI רמזים וביקורת, לא פתרון מלא לפני ניסיון אישי.
4. הוסף בדיקות, תיעוד, והסבר של החלטות ופשרות.
5. פתח PR וסמן אותו Ready for review רק כאשר כל בדיקות CI עברו.
6. השלם מבחן מעבר ורשום ראיות להתקדמות עם `python3 scripts/roadmap.py complete 08 --evidence <PR-or-path> --reflection <summary>`.
