# Stage 08 — Read-only Data Serving and Dashboards

**Track:** Core  
**Prerequisite:** 07  
**Outcome:** A loopback-only analytics API with a quality-aware dashboard, strict pagination and explicit data freshness.

[Guided notebook](../../notebooks/08_readonly_serving.ipynb) · [Hands-on lab](../../labs/08-serving/README.md) · [Assessment rubric](../../docs/ASSESSMENT.md) · [Full roadmap](../../README.md)

## Why this matters

- Allowlisted GET endpoints and SQLite read-only connections.
- Correct numerator/denominator for AVG with NULL magnitudes.
- Stale, empty, blocked and failed states.
- Browser CSP, safe text rendering and bounded pagination.

The goal is not to memorize tool commands. You must predict the output, write your own code, intentionally reproduce a failure, repair it, and explain the operational tradeoffs.

## Learning workflow

1. Open the guided notebook **visually** in VS Code, predict each assertion, then run its code cells. Use [the VS Code setup guide](../../docs/VS-CODE-LEARNING-SETUP.md) if the notebook opens as JSON.
2. Read the official documentation linked in the notebook or lab and sketch the data flow.
3. Run the instructor grader only to confirm the teaching exercise itself works:

~~~bash
python3 labs/08-serving/grade.py --reference
~~~

4. Run the learner grader and implement the unfinished starter. It is **expected to fail at first**:

~~~bash
python3 labs/08-serving/grade.py
~~~

5. Add tests, investigate one injected failure, record sanitized results and open a learner PR. Use AI for hints or code review after attempting the solution, not as a substitute for an independent exam.
The learner-specific KPI grader is `python3 labs/08-serving/learner/grade.py`, with reference check `--reference`.

## Required tasks

- [ ] Run 24 API/security tests and open the local dashboard.
- [ ] Implement the independent region KPI exercise and its 11 tests.
- [ ] Add a new safely parameterized regional summary endpoint in a practice branch.
- [ ] Force a missing database and prove the UI shows an error, not stale KPI values.

## Independent conceptual check (without AI)

1. Why does a SELECT-only endpoint still need authorization?
2. Why is old historical data different from an outage?

## Exit gate

Pass the API and independent KPI tests, with a new positive and negative HTTP test and a short security ADR.

You must also document assumptions, reproducible commands, risks and an original transfer scenario in your PR. No credentials, private data or unauthorized writes are permitted. Passing instructor CI does not certify a learner or prove production deployment.
