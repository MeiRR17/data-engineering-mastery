# Stage 08 — הצגת מידע ואנליטיקה: Read-only Data Serving

**קדם:** Stage 07 — חוזי נתונים, איכות ו־Lineage.  
**תוצר:** דשבורד מקומי שמראה מדדים, עדכניות, ריצות שנחסמו ו־API מוגבל לקריאה בלבד.

[**המעבדה המעשית של Stage 08**](../../labs/08-serving/README.md) · [רובריקת הערכה](../../docs/ASSESSMENT.md)

## מה לומדים?

- מימוש REST API עם נתיבי GET מפורשים ו־JSON מינימלי; לא חושפים SQL חופשי או Payload גולמי.
- גבול בין Source/Curated ו־Serving; קובץ SQLite נפתח במצב `mode=ro` וב־`query_only`.
- שלוש הגדרות מדד לפחות: מספר אירועים, ממוצע על ערכים ידועים ומצב עדכניות.
- טיפול ב־Empty/Loading/Error/Stale, וסימון ריצה שחסמה פרסום נתונים.
- Pagination מוגבל, בדיקת קלט ומניעת Data Leakage.
- אבטחת דפדפן בסיסית: Content Security Policy, הימנעות מ־HTML Injection ושימוש ב־`textContent`.

## הוראות קצרות

~~~bash
python3 labs/08-serving/grade.py
python3 labs/08-serving/serve.py
~~~

פתח `http://127.0.0.1:8765`. הנתונים סינתטיים והדוגמה מאזינה ל־Loopback בלבד.

## תרגיל מדדים מחייב

השלם את `labs/08-serving/learner/starter.py` ועבור 11 מבחני `python3 labs/08-serving/learner/grade.py`. ודא חישובי Region נכונים, ממוצע שאינו כולל NULL, מגבלות `limit`, וקריאה בלבד. בדיקות הייחוס: `python3 labs/08-serving/learner/grade.py --reference`.
