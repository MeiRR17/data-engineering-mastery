# שלב 10: עיבוד מבוזר — Big Data & Spark

**רמת יעד:** העמקה מתקדמת  
**שלבי קדם:** 09  
**תוצר מרכזי:** Batch אנליטי ב-PySpark עם בדיקות ביצועים

## למה לומדים את זה?
Spark/PySpark, shuffle, DAG execution, skew, partition strategies, columnar formats, explain plans.

## סדר עבודה
1. קרא את חומר הרקע והתיעוד הרשמי הרלוונטי (לא מדריך וידאו בלבד).
2. פתח Issue עם הסעיף הזה בריפו האישי שלך, וצור branch בשם `learn/10-<short-topic>`.
3. יישם את המשימות בעצמך. בקש מ-AI רמזים וביקורת, לא פתרון מלא לפני ניסיון אישי.
4. הוסף בדיקות, תיעוד, והסבר של החלטות ופשרות.
5. פתח PR וסמן אותו Ready for review רק כאשר כל בדיקות CI עברו.
6. השלם מבחן מעבר ורשום ראיות להתקדמות עם `python3 scripts/roadmap.py complete 10 --evidence <PR-or-path> --reflection <summary>`.
